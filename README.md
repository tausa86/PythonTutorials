Properties of Variables:
1. Variable Name must not be started with number 
e.g: 10 = 10 is not allowed

2. Variable names must be AlphaNumeric and underscore
e.g: Ten = 10, Twelve_12 = 12

3. Conventional, variable names must not start with underscore
4. Variable names must not use python keywords
e.g: import, def, if, else etc.
5. Variable names are case-sensitive
e.g: number, Number, nuMber are 3 different variables
